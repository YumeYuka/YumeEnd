欢迎来到 YumeBot 插件市场！这里汇集了各种实用插件，让您的机器人功能更强大。

## 官方插件

### 单插件 (Example Plugin)

<Card title="单插件" icon="Githbu" href="https://github.com/YumeYuka/YumeBot" horizontal>
    YumeBot 单 kt 插件统一放置到此位置, YumeBot 会自动注册并启用这些插件
</Card>

<Steps>
    <Step title="下载单个插件并添加到目录">
        `plugins/example/src/main/kotlin/plugins/example`
    </Step>

    <Step title="构建并运行">
        ```bash
        ./gradlew build
        ./gradlew run
        ```
    </Step>
    <Step title="检查日志">
        ```bash
        [20:46:18][INFO][Main] 自动注册插件: example
        [20:46:18][INFO][Main] 自动注册插件: genshin
        ```
    </Step>
</Steps>
