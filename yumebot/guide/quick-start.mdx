YumeBot 是基于 NapCatQQ 的 QQ 机器人框架，让您的 QQ 机器人快速拥有强大功能。

## 准备工作

开始之前，请确保您有：

- **Java 17 或更高版本**（检查：`java -version`）
- **一个 QQ 小号**（用作机器人账号，避免使用主号）
- **NapCatQQ**（QQ 机器人框架）

## 一、配置 NapCatQQ

### 1. 下载并安装

访问 [NapCatQQ Release](https://github.com/NapNeko/NapCatQQ/releases) 下载最新版本。

### 2. 登录机器人账号

启动 NapCatQQ，使用您的机器人 QQ 号登录。

<Warning>
  建议使用小号作为机器人账号，避免风控。
</Warning>

### 3. 配置 WebSocket 连接

在 NapCatQQ 中配置 WebSocket 客户端：

<Steps>
  <Step title="打开网络配置">
    进入 NapCatQQ 设置 → 网络配置
  </Step>
  
  <Step title="新建 WebSocket 客户端">
    点击"新建" → 选择"WebSocket 客户端"
  </Step>
  
  <Step title="填写连接地址">
    填写：`ws://127.0.0.1:5795/ws`
  </Step>
  
  <Step title="保存并连接">
    保存配置，确保连接状态正常
  </Step>
</Steps>

## 二、下载 YumeBot

打开终端，克隆 YumeBot 项目：

```bash
git clone https://github.com/YumeYuka/YumeBot.git
cd YumeBot
```

## 三、配置 YumeBot

在项目 `config` 目录下创建 `config.json` 文件：

```json
{
  "bot": {
    "selfId": 123456789,
    "nickname": "YumeBot"
  },
  "server": {
    "host": "127.0.0.1",
    "port": 5795,
    "accessToken": "",
    "timeout": 30000
  },
  "log": {
    "level": "INFO",
    "enableConsole": true,
    "enableFile": true,
    "logPath": "./logs",
    "maxFileSize": 10485760,
    "maxFiles": 7
  }
}
```

<Note>
  **配置说明**
  - `selfId`: 您的机器人 QQ 号
  - `nickname`: 机器人昵称
  - `host` 和 `port`: 必须与 NapCatQQ 的 WebSocket 地址一致
</Note>

## 四、启动机器人

在项目目录下运行：

<Tabs>
  <Tab title="Windows">
    ```bash
    .\gradlew.bat run
    ```
  </Tab>
  <Tab title="Linux / macOS">
    ```bash
    ./gradlew run
    ```
  </Tab>
</Tabs>

<Note>
  首次运行会下载依赖，需要等待几分钟。
</Note>

## 常见问题

<AccordionGroup>
  <Accordion title="连接失败？" icon="wifi-off">
    **可能原因**：
    - NapCatQQ 未启动或未正常登录
    - WebSocket 地址配置错误
    - 端口 5795 被其他程序占用
    
    **解决方法**：
    1. 确认 NapCatQQ 正在运行且已登录
    2. 检查 `config.json` 中的 `host` 和 `port`
    3. 确认 NapCatQQ 的 WebSocket 客户端配置正确
    4. 检查防火墙是否阻止连接
  </Accordion>
  
  <Accordion title="机器人不回复？" icon="message-x">
    **可能原因**：
    - 机器人未加入测试群
    - 机器人被禁言
    - 关键词不匹配
    
    **解决方法**：
    1. 确认机器人已加入群聊
    2. 检查机器人是否被禁言
    3. 尝试发送其他命令测试
    4. 查看控制台日志排查问题
  </Accordion>
  
  <Accordion title="找不到 Java？" icon="coffee">
    **可能原因**：
    - 未安装 Java
    - Java 版本过低
    - 环境变量未配置
    
    **解决方法**：
    1. 下载安装 [Java 17+](https://adoptium.net/)
    2. 配置环境变量
    3. 重启终端后再试
  </Accordion>
  
  <Accordion title="下载依赖太慢？" icon="clock">
    **可能原因**：
    - 网络问题
    - Maven 仓库连接慢
    
    **解决方法**：
    1. 等待首次构建完成（仅首次较慢）
    2. 配置国内 Maven 镜像
    3. 使用稳定的网络环境
  </Accordion>
</AccordionGroup>
